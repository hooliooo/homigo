# Introduction and Goals
homigo (pun on home and amigo) is an application that manages the household. It contains functionality such as budgeting,
grocery lists, inventory, chores/task list and calendar reminders to help the user get an overview of their household.
This is a hobby project and is meant to be both a learning experience in Rust and a tool that helps with everyday life

## Requirement Overview 

The following is a list of features that homigo will contain:

- Budget Planning and Bookkeeping
  - Transaction history
  - Data overview
    - Categorization
    - Time-based reports
- Grocery Planning
  - List creation
  - Categorization
- Inventory Management
- Chore Planning
  - List creation
  - Reminders
- Calendar
  - Overview
  - Reminders
